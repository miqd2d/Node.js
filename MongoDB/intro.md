# Mongo DB
- MongoDB is a cross platform, document oriented database that provides high performance, high availability and easy scalability, MongoDB works on concept of collection and document.

### Database
- A physical container for collections. Each database gets its own set of files on the file system. A single MongoDB server typically has multiple interface , database.

### Collections
- A group of MongoDB document. It is an equivalent to RDBMS table. A collection do not enforce a schema, document within a collection can have different fields.

### Documents
- A document is a set of key-value pair. Document have dynamic schema. ___Dynamic schema___ means that document in the same set of fields and structure and common fields in a collection document may hold different types of data.
